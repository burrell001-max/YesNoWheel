Country Picker Wheel

        196 countries on one wheel

        The wheel carries 196 entries: the 193 United Nations member states, plus Palestine, Taiwan and Vatican City. Each one is a single slice and every slice is the same size, so any country has a 1-in-196 chance. Names run alphabetically, and no slice carries a flag, a capital city or a population figure, because the draw is about which country comes up, not how much you already know about it.

        A handful of entries use a short form so the label still fits a phone screen. The Democratic Republic of the Congo appears as DR Congo, and Cote d'Ivoire is written without its accent. The country is the same either way, and the text view accepts the long form if you would rather see it spelled out.

        How to run it

        Press Spin, use the space bar, or click the hub at the centre of the wheel. The pointer marks the winning slice and a pop-up names the country.

        • Elimination mode offers Hide choice after each win, which is the setting for a class that studies one country a week: after 30 weeks, 30 different countries.
        • The text view is how you cut the list to a continent, a language region or a set of countries you are actually travelling to.
        • Accumulation mode leaves every country in play and counts the draws, which is useful across a term of quiz rounds.
        • The share link hands the exact list you built to someone else, so two classes can work from the same 196 or the same dozen.

        Five ways to use a country draw

        Country of the week

        Spin once on Monday, then spend a page on the country it lands on: where it is, what language is spoken, one dish, one landmark. Elimination mode stops the same country returning next week.

        Cook the country

        Draw a country and find one dish you can actually cook with what is in the shop. It works better as a food project than as a quiz question, because the result is eaten.

        Capital quiz

        Spin and give the group ten seconds to name the capital before the next spin. Because nobody picks the country, the quiz covers the map instead of the same five places.

        Travel shortlist

        Cut the list to countries you would genuinely visit this year, then spin. A draw among ten real options is more useful than a draw among 196.

        Language practice

        Draw a country, then write two sentences in its main language, or find one news story from it. The wheel picks the topic; the work is still the work.

        Questions people ask

        Which countries are included?

        The 193 UN member states plus Palestine, Taiwan and Vatican City: 196 entries in total. The full list is printed above and comes from the same data the wheel uses.

        Why are some names shortened?

        A long official name takes up most of a slice on a small screen, so the common short form is used. The text view accepts the full name if you want it back.

        Can I spin one continent at a time?

        Yes. Delete the other entries in the text view and the wheel redraws with the countries you kept.

        Are flags or capitals shown on the slices?

        No. The slices carry country names only, so the wheel stays readable on a phone.

        Does elimination mode remember my progress?

        Hidden countries are saved in your browser and stay hidden until you use Restore hidden. The list is rebuilt from all 196 each time the page opens, so a trimmed list lasts for the visit.

        Can I use it offline in a classroom?

        Once the page has loaded, the wheel runs in the browser without a connection, so a dropped school network does not stop the draw.
