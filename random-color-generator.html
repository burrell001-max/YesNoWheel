Color Picker Wheel

        Sixteen colour names on the wheel

        The default list is sixteen common colours: red, orange, yellow, green, teal, blue, indigo, purple, pink, brown, black, white, gray, gold, turquoise and maroon. They are broad names on purpose. Blue is one slice, not a hundred shades of it, because the draw is meant to give you a direction rather than a specification.

        The colour a slice is painted in comes from the wheel palette in Settings, not from the name on it. A slice labelled green may be drawn in yellow, and that is deliberate: the palette keeps the wheel legible, while the label is the thing being chosen. Nothing on this page returns a colour code.

        Each of the sixteen has the same 1-in-16 chance, and adding a name gives it its own slice rather than nudging the others.

        How to use it

        Tap Spin, press space, or click the hub at the centre of the wheel. The colour name then appears in a pop-up, written in the same words as the slice.

        • The text view is where you add names: coral, navy, sage, mustard, or the exact words your group uses for colours.
        • Elimination mode offers Hide choice after each draw, which is how you build a palette of three without repeating one.
        • The palette in Settings changes how the slices look, so you can match the wheel to a project or keep it neutral.
        • Weights let you push a palette towards the colours you actually have to hand, for example when a pack of pencils only contains twelve.

        Five ways to use a colour draw

        Two-colour art prompt

        Spin twice for a pair, then a third time for the background. The constraint is the exercise: a drawing that has to work in two colours, chosen without you, is a different problem from a free choice.

        Outfit decision

        Spin once before opening the wardrobe and wear that colour as the main one. It is a small decision that otherwise takes five minutes and three changes.

        Craft and paint projects

        Draw a colour and use only what you already own in that family. It stops a craft session turning into a shopping trip.

        Team colours

        Spin once per team in elimination mode so no two teams end up with the same colour, then use the result for bibs, cards or a scoreboard.

        Party or classroom theme

        Draw a colour for the week and build one small thing around it: a display, a snack, a playlist cover. One colour is a manageable theme; five is a project.

        The sixteen names, and what they are not

        The list is deliberately short and plain. Each name is a category, not a shade, so "blue" covers everything from a pale sky to a deep navy, and "gold" is a name rather than a metallic finish.

        • Warm: red, orange, yellow, gold, pink
        • Cool: teal, blue, indigo, turquoise
        • Neutral: brown, black, white, gray
        • In between: green, purple, maroon

        If you need a specific shade, add it as a name and use a design tool to match it. This wheel picks words; it does not mix paint, generate hex codes or check contrast.

        Questions people ask

        Does the wheel show the exact colour?

        It picks a colour name. The slices use the wheel palette from Settings, which you can change, so the paint on a slice is not necessarily the colour it names.

        Can I add my own colours?

        Yes. Add one name per line in the text view and each becomes its own slice with an equal chance.

        Can I use a hex code as an entry?

        Yes, entries are plain text, so a code like #1E90FF works as a label. The wheel will not render that shade; copy the code into a design tool for that.

        Is this a colour wheel for design work?

        No. It is a random picker for names, useful for games, crafts and prompts. For harmonies, contrast checking or palettes, use a design tool.

        How do I get three colours without repeats?

        Switch to Elimination mode and hide each winner, so three spins give three different names.

        Is the colour wheel free?

        It is free, with no account and no cap on how many times you spin.
