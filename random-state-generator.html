State Picker Wheel

        Fifty states, one slice each

        The wheel holds all 50 US states, from Alabama through Wyoming, in alphabetical order. Each state is a single slice and every slice is the same size, so a spin is a 1-in-50 draw. The labels are state names only: no abbreviations, no capitals and no rankings are mixed into the list, because a state drawn for a school assignment should not need a second decision.

        Washington, D.C. and the US territories are not on the wheel by default. If your group counts them, add them in the text view and they take their place as ordinary slices.

        How to use it with a group

        Press Spin, click the wheel, or use the space bar. The pointer marks the winner and a pop-up names the state.

        • Elimination mode is the one that matters for teaching: a state is removed once it has been drawn, so a class of 28 gets 28 different states with no repeats and no redraws.
        • Accumulation mode keeps every state on the wheel and counts the draws, which is useful across a term of quiz rounds when you want to see which states came up most.
        • The text view is where you cut the list down: keep one region, drop the states your class has already covered, or add territories and D.C.
        • The share link in the settings panel gives you a wheel you can send to a colleague so both classes start from the same list.

        Five ways to use a state draw

        State report assignments

        Run elimination mode in front of the class and let each student spin once, or spin for them. Nobody can claim the teacher handed out the harder states, and the list of who got what can be read back from the result history.

        Capital quiz

        Spin for a state and give ten seconds to name its capital before the next spin. Because the state is drawn rather than chosen, the quiz covers the map instead of circling the same dozen places.

        Blank map drill

        Hand out an outline map, spin, and have students mark the state it names. Three spins make a quick warm-up; ten make a scored round.

        Road trip planning

        Spin once for a direction and once more to commit: the first state sets the route, the second is where you stop. Use elimination for a multi-stop trip so the wheel cannot send you back through the same state.

        Regional bingo

        Cut the wheel down to one region in the text view, then read draws aloud while players cross off states on a bingo card built from the same region.

        Questions people ask

        Does the wheel include Washington, D.C.?

        No. The 50 slices are the states only. Add D.C. or a territory in the text view if your lesson or game counts them.

        Can I use it for state capitals instead?

        Yes. Replace the 50 state names with the 50 capitals, one per line, and the wheel becomes a capital picker. The states stay on the page until you change the list.

        How many spins to cover every state?

        Fifty, in Elimination mode. In normal mode a state can repeat, so the count to cover all 50 is longer and varies.

        Can I remove the states we have already studied?

        Yes. Open the text view and delete those lines. The wheel redraws with the remaining states and their chances even out.

        Is the state list kept between visits?

        Yes, on the same device and browser. The list is stored locally, so a class set you trimmed is still trimmed next week.

        Does it work on a phone in class?

        The wheel, the spin button and the result pop-up scale to a phone screen, so one student can hold the device while the class watches.
