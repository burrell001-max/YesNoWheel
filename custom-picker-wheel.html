Custom Picker Wheel

        A wheel for a list you write yourself

        The custom picker is the general-purpose version of this site: the other wheels arrive with a known set of entries, and this one arrives empty so you can supply the set. Names, chores, raffle tickets, films, tasks, prizes, anything that can be written on one line can go on a slice.

        Because you write the list, you also control the odds. Each entry carries a weight, so a ticket holder with six tickets can be six times as likely as one with a single ticket, and every slice can carry its own color or picture. Nothing is uploaded and no account is involved: the list lives in the browser you are using.

        How to use it

        Open the Inputs tab and add entries in either view. The list view gives each entry a row with a weight box, a color control and an image button. The text view is a plain box where every line is one entry, which is the faster route for a list you already have in a spreadsheet or a message.

        Press Spin, press the space bar or click the hub. The result opens in a pop-up, and in Elimination mode that pop-up also carries the Hide choice and Hide all matching buttons. The second one removes every entry with the same name, which is how a duplicated name is cleared in one click.

        These are the controls that actually exist, and what each one does:

        • Weights. Each entry runs from 0 to 999 in steps of 0.5. A weight of 2 doubles an entry's chance; a weight of 0 keeps the line but drops it from the wheel. In the text view, a line beginning 6, Ada sets Ada's weight to six.
        • Colors. Every entry can take a color, and Settings offers palettes called vibrant, pastel, neon, mono and custom, plus a page background color and a center label.
        • Images. An entry can hold an image address or an uploaded picture, shown inside its slice and in the result pop-up.
        • Normal, elimination and accumulation. Normal keeps every slice in play; elimination hides winners as you go; accumulation counts wins and shows a leaderboard.
        • List tools. Shuffle, sort A to Z, delete empty lines and clear all sit above the list.
        • Import and export. CSV, TXT and JSON files can be imported, and the wheel exports as CSV or JSON, with text, weight, color and hidden state in the CSV.
        • Share and embed. Settings builds a link that carries the list in the address, and an iframe version of the same wheel.

        Spin behavior is adjustable too: the duration slider runs from 1 to 15 seconds, speed from 1 to 10, and the tick, victory sound, confetti, idle spin and dark theme are separate switches.

        A worked example: a weighted raffle

        Suppose a school raffle sells tickets in strips, so one family holds six tickets and another holds one. A plain wheel with one entry per person would give both families the same chance, which is the wrong answer. Here is the whole setup.

        1. Clear the default entries with Clear all, then open the text view.
        2. Write one line per ticket holder, starting with the number of tickets they hold: 6, Ada, 6, Ben, 1, Cara. The number before the comma becomes the weight.
        3. Check the list view. Each row should show the weight you typed; the slices are now sized in proportion to tickets sold.
        4. Choose Elimination mode, because a prize draw should not hand the same family two prizes unless the rules allow it.
        5. Spin for the first prize. In the pop-up, press Hide choice so that winner leaves the wheel, then spin again for the next prize.
        6. Open the Results tab to read the order of winners, and export the history as CSV if the draw needs a written record.

        Two extras are worth knowing. The share link sends the whole weighted list to a colleague, so a second person can watch the same draw; the embed code puts that wheel on the raffle page itself. And if the draw is happening in front of an audience, raise the spin duration so nobody can claim the result arrived too fast to see.

        Making a list that spins well

        • One idea per line. A line that says "Movie night or takeaway" is two options hiding in one entry, and the wheel can only pick the pair.
        • Keep it readable. Under twenty entries the labels stay legible on a phone; a hundred entries need a shorter list or a spoken draw.
        • Trim near-duplicates. Three versions of the same restaurant split one preference across three slices, which quietly changes the odds.
        • Reserve weights for real differences. Ticket counts and seniority are reasons; liking an option more is not, unless the group agreed to it first.
        • Use colors to group. One color per team or category turns a crowded wheel into something readable at a glance.
        • Export before clearing. A CSV takes a second to save and turns a lost browser session into a minor annoyance.

        Questions people ask

        How many entries can one wheel hold?

        Five hundred. Past a few dozen slices the labels get cramped, so a shorter list is easier to read from across a room.

        Why did my entries disappear?

        The page keeps entries in this browser on this device. Clearing site data, using a private window or switching browsers starts you with an empty wheel, so export a CSV of anything you want to keep.

        Can a slice show a picture instead of text?

        Yes. Each entry has an image control that accepts a pasted address or an uploaded file, and the picture is drawn inside that slice.

        What does a weight of 0 do?

        It keeps the entry in the list but takes it off the wheel. That is useful for a name or prize you want to leave out of this round without deleting it.

        Do entries keep their color when I paste a new list?

        Yes, when the text matches. The wheel pairs a pasted line with an existing entry of the same name and reuses its color, weight and picture. A new name arrives with the default styling.

        Can I put the wheel on my own website?

        Yes. Settings has an embed code, an iframe pointed at this page with your list in the address. Paste it into a page that allows iframes and the wheel runs there.
